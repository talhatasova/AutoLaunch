# 01: Sign in and reach the app

**What to build:** A founder can enter the application host, sign in with email or Google, and make a protected FastAPI request while the marketing host remains public.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Both hosts route to the intended surface.
- [ ] Invalid or absent authentication cannot read another founder's data.
- [ ] A runnable check covers authenticated and unauthenticated API access.

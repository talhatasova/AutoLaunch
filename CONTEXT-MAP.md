# Context Map

## Contexts

- [Marketing](./docs/contexts/marketing/CONTEXT.md): explains the product and its promise to prospective founders.
- [Application](./docs/contexts/application/CONTEXT.md): owns founder products, the directory catalog, and selection of submission targets.
- [Submission](./docs/contexts/submission/CONTEXT.md): records each directory submission and distinguishes a receipt from a live listing.

## Relationships

- Application gives Submission an approved product profile and eligible directory targets.
- Submission reports progress and evidence back to Application for the founder's dashboard.
- Marketing describes only behavior the other contexts can deliver.

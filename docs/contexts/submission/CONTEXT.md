# Submission

The lifecycle of sending a product to a directory and establishing whether its listing is public.

## Language

**Submission**:
The founder-authorized request to send one product to one directory. A failed submission may be retried without creating a second active request.

**Receipt**:
Evidence that a directory accepted the submission for processing. A receipt does not establish that the product is publicly listed.

**Unconfirmed submission**:
A submission for which the send action occurred but the directory gave no reliable receipt. Its outcome requires investigation before another attempt.

**Live listing**:
A public directory page for the product, backed by a verifiable URL.
_Avoid_: Successful submission

# Issue tracker: local Markdown

Issues and specs for this repo live under `.scratch/<feature-slug>/`.

- The spec is `spec.md` in the feature directory.
- Implementation tickets are separate files in `issues/<NN>-<slug>.md`, numbered in dependency order.
- Each ticket records its `Blocked by` and `Status` near the top. Use the states in `triage-labels.md`.
- Append discussion under `## Comments`.

When a skill says to publish a ticket, create its file. When it says to fetch a ticket, read that file.
